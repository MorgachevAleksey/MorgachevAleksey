## Проект: Vally

Сервис валютных операций: получение актуальных котировок от ЦБ РФ и кросс-конвертация между валютами.

**Статус:** 
Активно развиваю как основной проект

**Архитектура:** 
Слоистая: Controller → Service → Provider → Loader → Client → API ЦБ
- Есть отдельный слой Маппера, который переводит внешний контракт данных от ЦБ во внутренний DTO и обрабатывает данные
- Общение между слоями осуществляется посредством DTO
- Контракт API изолирован от слоя бизнес-логики c помощью слоев Провайдера и Лоадера
- Проект готов к масштабированию без изменения сервисного слоя: для Провайдера реализован интерфейс, а для Клиента конфиг
- Все иньекции зависимостей строго через конструктор

**Реализовано:**
- Эндпоинты: список курсов (`/rates`), конвертация (`/exchange`), приветственная страница (`/`)
- Валидация запросов
- Глобальная обработка ошибок с унифицированным форматом ответа
- Кэширование
- Покрытие тестами (в частности слой маппера)
- Интерактивная документация API (Swagger UI)

**В разработке:**
- Сохранение истории операций и курсов валют в postgreSQL через Docker
- Подключение других источников API
- Пользовательский слой
- Расширение тестового покрытия

**Стек:**
- Java 21
- Spring Boot 4.1
- Gradle
- REST API (Jackson)
- Spring Cache + Caffeine
- Spring Validation
- Spring Test + JUnit5
- Springdoc OpenAPI (Swagger)
