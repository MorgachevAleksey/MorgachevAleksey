## Проект: Vally

Сервис валютных операций: получение актуальных котировок от ЦБ РФ и кросс-конвертация между валютами.

**Архитектура:** Слоистая: Controller → Service → Provider → Loader → Client → API ЦБ
- Есть отдельный слой Маппера, который переводит внешний конракт данных от ЦБ во внутренний DTO и обрабатывает данные
- Общение между слоями осуществляется по средству DTO
- Контракт API изолирован от слоя бизнес-логики c помощью слоев Провайдера и Лоадера
- Проект готов к масштабированию без изменения сервисного слоя: для Провайдера реализован интерфейс, а для Клиента конфиг
- Есть кэширование данных

**Реализовано:**
- Эндпоинты: список курсов (`/rates`), конвертация (`/exchange`)
- Чистое разделение ответственности между слоями

**В разработке:**
- Тесты
- Валидация запросов
- Глобальная обработка ошибок
- Подключение postgreSQL
- Подключение альтернативных API

**Статус:** Aктивно развиваю как основной проект

[Vally](https://github.com/MorgachevAleksey/Vally)
